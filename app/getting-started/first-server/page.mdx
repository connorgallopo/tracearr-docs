# Connect a Server

After installing Tracearr, the first page you open is setup. It connects your first media server and can import its history.

## Initial Setup

Setup has four steps, listed down the side of the page:

1. **Media server**: pick Plex, Jellyfin, Emby or tofa. This is the first server you connect; you can add others later in Settings.
2. **Owner account**: create the account that manages Tracearr. Read [The owner account](#the-owner-account) first.
3. **Connect server**: connect a server of the type you picked.
4. **Import history**: bring in plays from before Tracearr was watching. See [Import Watch History](/getting-started/import).

With Plex or tofa, **Continue with Plex** or **Continue with tofa** on the second step creates the owner from that account and connects the server you pick, so setup goes straight to the import step. You can also create the owner with a username and password and connect the server afterwards. Jellyfin and Emby always take the username and password route.

**Connect server** and **Import history** both have **Skip**. A skipped server can be added later from **Settings** → **Servers** → **Connections**. An import keeps running in the background once it starts, so **Go to dashboard** doesn't wait for it.

### The owner account

The first account created on a fresh install becomes the owner, and there is only ever one. Once it exists the login page stops offering sign-up and there is no way to create another Tracearr account. Everyone else comes in through their own Plex, Jellyfin, Emby or tofa account; see [Member sign-in](/configuration/member-sign-in).

Create the owner as yourself, from your own media server account or with its details. Tracearr records plays against people, and each person is one identity that holds their accounts on your servers. Your own Plex, Jellyfin, Emby or tofa account is one of those accounts, and it should belong to the owner instead of showing up as a second person.

How your own account joins the owner depends on how you set it up:

- **Continue with Plex** or **Continue with tofa** creates the owner from that account and attaches your account on the server you pick right away.
- **Create Account** asks for a display name, username, email and password. When Tracearr syncs a Plex or tofa server's accounts, an account whose email matches an existing person's email joins that person. Give the owner the same email as your Plex or tofa account and that account becomes part of the owner. Matching is by email only. A matching username links nothing.
- Jellyfin and Emby do not send Tracearr any email addresses, so a Jellyfin or Emby account never joins the owner on its own, whatever you type here. Your own account shows up on **Users** as a separate member until you [link it](#linking-your-own-jellyfin-or-emby-account).

When the owner and your own server account end up as two people, plays on that account are recorded under the member, not the owner, and signing in with it through Jellyfin or Emby follows the member rules instead of signing you in as the owner. Renaming does not join them. A person's display name can be changed from their page, the username cannot be changed in the web app, and a synced account never joins a person by username. Two people who are both listed on **Users** can be [merged](/faq#how-do-i-merge-two-users-into-one-person). The owner is never listed there, so your own Jellyfin or Emby account is linked from its server instead.

#### Linking your own Jellyfin or Emby account

In **Settings → Servers → Connections**, each Jellyfin and Emby server row has a **Your account** line with a **Link your account** button. Pick the account you use on that server and type its username to confirm. When the server has exactly one administrator, that account is already selected.

On a tofa server the same button asks you to sign in to tofa as the account you use on that server, instead of picking from a list. Signing in with tofa then opens Tracearr as you.

Linking folds that account into the owner the same way a merge does. Its plays become yours, and signing in with it through the **Media server** form signs you in as the owner, on a server open to member sign-in. Anyone who can sign in to the server as that account gets the same access: whoever knows its password, anyone who manages the server, and on Jellyfin any device signed in to it that approves a Quick Connect code. Only link your own account.

Tracearr refuses the link when:

- you already have an account linked on that server
- the person holding the account also has accounts on other servers; split it off on their page first
- that person is an admin or has their own Tracearr password or SSO sign-in
- the account has been removed from the server

**Unlink** followed by the account's username, in the row's menu, moves the account back out to a person of its own and signs you out of Tracearr everywhere except the browser you used and your paired phones. While none of your Jellyfin or Emby accounts are linked and you have no plays, the **Personal** dashboard points you to this setting.

### Plex

1. Pick **Plex** on the first step and click **Continue**
2. Click **Continue with Plex** and sign in to plex.tv in the window that opens
3. Tracearr lists the Plex servers on that account. Pick the one to monitor
4. Setup moves on to **Import history**

<Callout type="info">
  Plex servers must be owned by (or shared with admin access to) the Plex account you sign in with.
</Callout>

If you create the owner with a username and password instead, the **Connect server** step asks you to link a Plex account and then lists its servers.

### tofa

1. Pick **tofa** on the first step and click **Continue**
2. Click **Continue with tofa**. A tofa window opens: sign in and choose **Approve**. If tofa asks for a code, Tracearr shows it on the page. The code expires, and **Sign in again** starts over
3. Tracearr lists the tofa servers your account owns. Only a server's owner can connect it
4. Click **Connect** on the server. Tracearr creates its own API key on that server, which can read activity and stop streams
5. Setup moves on to **Import history**

Tracearr creates the key at the local address tofa lists for the server. When it can't reach that address, or tofa lists none, the row says so and asks for the **Server URL** to use, such as `http://192.168.1.100:33333`.

When your tofa account owns no servers, setup says there is nothing to connect yet. When the server you pick has no account for the tofa account you signed in with, setup refuses it, since you could not sign back in with tofa. In both cases create the owner with a username and password instead.

A tofa server needs tofa 0.13.3 or newer.

#### Connecting with an API key

**Enter a URL and API key instead**, under the sign-in button, takes the Server URL, a Server Name and an API key, the same as Jellyfin and Emby. Create the key in tofa under **Settings** → **API**:

- **Read only, can stop streams** covers everything Tracearr does.
- **Full admin** works too.
- **Read only** works, but Tracearr can't stop streams with it. The server's row then shows a **Can't stop streams** badge.

### Single Sign-On (OIDC)

If your Tracearr instance is configured with an OIDC identity provider (Authentik, Authelia, Keycloak, and similar), the login page shows an SSO button. Click it to sign in through your provider, then connect servers as described below. On a fresh install the first account created this way becomes the owner. An owner created with **Create Account**, Plex or tofa signs in through SSO only when the email on the IdP profile matches the owner's own Tracearr email: the one entered at **Create Account**, or the Plex or tofa account's email after signing in with it. Your server accounts' emails and the contact email are not checked. Use the same email in both places, or change the owner's with [`set-email`](/configuration/recovery#set-email). See [OIDC Single Sign-On](/configuration/environment#oidc-single-sign-on) for the required environment variables.

### Jellyfin and Emby

1. Pick **Jellyfin** or **Emby** on the first step and click **Continue**
2. Fill in the display name, username, email and password, and click **Create Account** (read [The owner account](#the-owner-account) first)
3. On **Connect server**, enter your server details:
   - **Server URL**: for example `http://192.168.1.100:8096`
   - **Public address**: optional, see [Public address](#public-address)
   - **Server Name**: a friendly name for the server
   - **API Key**: see [Getting API Keys](#getting-api-keys)
4. Click **Connect Server**. Setup moves on to **Import history**

### Public address

Both the Jellyfin and the Emby form carry one more field, **Public address**, which is optional and has no equivalent on Plex or tofa, whose links open in their own web apps. It is the address members use to open the server from outside your network, such as `https://jellyfin.example.com`, and newsletter links use it.

Tracearr always talks to the server on the Server URL. The public address is only ever put into links other people click, so setting it changes nothing about polling, sessions or the API key. Leave it blank and newsletters carry no links to items on that server. Give it an address a member off your network could not open, such as an RFC 1918 or loopback address, a Tailscale `100.64.0.0/10` address, or a `.local` or `.ts.net` name, and the links are left out for the same reason; the newsletter editor's Readiness list names the server and says which of the two it hit.

<Callout type="info">
  Jellyfin and Emby sessions are detected by polling out of the box. For instant, push-based
  sessions like Plex and tofa, install the [Tracearr SSE plugin](/configuration/realtime).
</Callout>

<Callout type="info" title="Who signs in with what">
  The owner signs in with a local Tracearr account, Plex, tofa, SSO, or their own Jellyfin or Emby
  account on a server with member sign-in on, once that account is [linked to the
  owner](#linking-your-own-jellyfin-or-emby-account); Jellyfin and Emby are connected with an API
  key as described above. The people you share a server with can sign in with their own Plex,
  Jellyfin, Emby or tofa account once you allow it; see [Member
  sign-in](/configuration/member-sign-in). If your install only ever signed in with Jellyfin
  credentials before 1.5.0, see [Account Recovery](/configuration/recovery) to regain access to the
  owner account.
</Callout>

## Adding More Servers

You can monitor multiple servers from a single Tracearr instance. Click **Add Server** in **Settings** → **Servers** → **Connections**, pick the server type, and fill in the same fields as above. You'll need administrator access to generate a Jellyfin or Emby API key. Once the server is connected, the dialog offers the same history import as setup.

Plex servers come from linked Plex accounts. To add one owned by a different Plex account, link that account first under [Plex accounts](/configuration/servers#linking-another-account). A tofa server is added by signing in to tofa as its owner, or with **Enter a URL and API key instead**.

Changing a server's URL or API key later is covered in [Media Servers](/configuration/servers).

## Getting API Keys

### Jellyfin

1. Open Jellyfin and go to **Dashboard** → **API Keys**
2. Click the **+** button to create a new key
3. Give it a name (e.g., "Tracearr")
4. Copy the generated key

### Emby

1. Open Emby and go to **Dashboard** → **API Keys**
2. Click **New API Key**
3. Give it a name (e.g., "Tracearr")
4. Copy the generated key

### tofa

Signing in to tofa makes the key for you. For **Enter a URL and API key instead**, create one in tofa under **Settings** → **API** with **Read only, can stop streams**; see [Connecting with an API key](#connecting-with-an-api-key).
